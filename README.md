# GrabMAIL

A lightweight command-line tool for authorized email-related testing and research environments.

> [!WARNING]
> **Responsible Use:** Use this project only on systems, accounts, and data that you own or have explicit permission to test. The author is not responsible for misuse or unauthorized access.

## 📋 Requirements

Before installing GrabMAIL, make sure your environment meets the following requirements:

* Ubuntu 14.04 – 20.04 LTS
* SSH access
* Git
* Bash

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/annaqitty/GrabMAIL.git
```

### 2. Enter the project directory

```bash
cd GrabMAIL
```

### 3. Make the script executable

```bash
chmod +x anna.sh
```

### 4. Run the script

Follow the instructions provided by the project after installation.
