GrabMAIL

A lightweight command-line project designed for authorized email-related testing and research environments.

Disclaimer: Use this project only on systems, accounts, and data that you own or have explicit permission to test. The author is not responsible for misuse or unauthorized access.

📋 Requirements

Before installing GrabMAIL, make sure your environment meets the following requirements:

Ubuntu 14.04 – 20.04 LTS
SSH access
Git
Bash
🚀 Installation

Clone the repository and enter the project directory:

git clone https://github.com/annaqitty/GrabMAIL.git
cd GrabMAIL

Make the main script executable:

chmod +x anna.sh

Run the project according to the documentation provided in the repository.
